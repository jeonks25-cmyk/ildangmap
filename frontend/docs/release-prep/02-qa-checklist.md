# [2단계] 실사용 QA 체크리스트

**목적:** 출시 전 핵심 사용자 여정 수동 검증  
**원칙:** Pass / Fail / N/A / Blocked 기록, Fail 시 스크린샷·재현步骤 필수  
**환경:** 모바일 Chrome/Safari 우선 (768px 이하), PC는 보조

---

## 공통 사전 조건

| # | 항목 | Pass |
|---|------|------|
| 0-1 | 앱 로드 (`/map`) | ☐ |
| 0-2 | 하단 4탭(지도·일정·인원·설정) 전환 | ☐ |
| 0-3 | 로그인 상태 확인 (Mock 또는 카카오) | ☐ |

**테스트 계정:** Mock 로그인 또는 카카오 실계정 1개  
**기록:** 테스터명 / 날짜 / 기기 / URL(포트)

---

## 지도

| # | 시나리오 | 단계 | 기대 결과 | P/F | 비고 |
|---|----------|------|-----------|-----|------|
| M-1 | **장소 등록** | 지도 → + 또는 등록 진입 → 위치·제목·공종 입력 → 저장 | 지도에 마커 표시, 목록에 노출 | ☐ | 로그인 필요 시 프롬프트 |
| M-2 | **장소 수정** | 등록한 장소 선택 → 수정 → 필드 변경 → 저장 | 변경 내용 반영, 새로고침 후 유지 | ☐ | |
| M-3 | **장소 검색** | 검색창에 지명·주소 입력 | 결과 목록, 선택 시 지도 이동 | ☐ | |
| M-4 | **목록 보기** | 지도 목록/필터 UI | 현재 영역·필터 장소 리스트 | ☐ | |
| M-5 | **내 위치** | 내 위치 버튼 | 현재 위치로 지도 이동, (권한 허용 시) | ☐ | 거부 시 안내 확인 |

**지도 실패 시 자주 보는 증상:** SDK 미로드(빈 지도), 터치 불가, 검색 후 패널 안 닫힘

## 일정

| # | 시나리오 | 단계 | 기대 결과 | P/F | 비고 |
|---|----------|------|-----------|-----|------|
| S-1 | **일정 등록** | 일정 탭 → 날짜 선택 → + → 현장/개인 입력 → 저장 | 캘린더·당일 목록에 표시 | ☐ | |
| S-2 | **일정 수정** | 기존 일정 탭 → 수정 → 저장 | 변경 반영 | ☐ | |
| S-3 | **일정 삭제** | 일정 상세/목록에서 삭제 | 목록·캘린더에서 제거 | ☐ | |
| S-4 | **기간 일정** | 시작일 ≠ 종료일 (현장 일정) | 여러 날 표시, 현장 상세에서 기간·날짜별 배정 | ☐ | `ScheduleEntryComposerSheet` |
| S-5 | **OCR 일정** | 일정 추가 → 캡처 이미지 OCR 또는 붙여넣기 | 필드 자동 채움 → 수정 후 저장 | ☐ | OCR 10~30초 소요 |

**현장 상세 (`/schedule/field/:id`):** 현장정보 / 게시판 / 일정 / 변경이력 탭 동작 ☐
