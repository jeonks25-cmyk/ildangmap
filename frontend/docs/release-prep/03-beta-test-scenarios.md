# [3단계] 베타 테스트 시나리오 (오야지 5명)

**기간:** 3~5일 권장  
**목표:** 실제 현장 운영 흐름에서 막히는 지점 수집 (기능 추가·UI 변경 없음)  
**접속:** 공유 URL + (선택) Mock 로그인 또는 카카오 실로그인

---

## 참여자 안내 (카카오톡/문자용)

```
일당맵 베타 테스트에 참여해 주셔서 감사합니다.

① 아래 링크를 휴대폰 Chrome/Safari로 열어 주세요.
② [설정] → 로그인 (안내에 따라 진행)
③ 첨부 시나리오 3개만 순서대로 해 보시고
④ 피드백 양식(구글폼/노션)을 작성해 주세요.

버그·불편은 스크린샷과 함께 적어 주시면 큰 도움이 됩니다.
소요 시간: 약 20~30분
```

---

## 시나리오 A — "내일 현장 잡기" (필수, ~10분)

**상황:** 내일 단기 촬영 현장이 생겼다.

1. **지도** 탭에서 현장 위치를 찾거나 내 위치 근처 확인
2. **장소 등록:** 현장명·날짜·공종 입력 후 저장
3. 지도에서 방금 등록한 마커가 보이는지 확인
4. **일정** 탭 → 내일 날짜 → 방금 현장과 연결된 일정 확인 (또는 일정 직접 등록)
5. **기간:** 하루가 아니라 2~3일이면 시작일·종료일 다르게 등록

**성공 기준:** 지도·일정 양쪽에서 같은 현장을 찾을 수 있다.

**기록할 것:**
- 어느 단계에서 막혔는지
- 버튼/글자가 작거나 헷갈린 부분
- 저장 후 사라졌는지

---

## 시나리오 B — "팀원 소집" (필수, ~8분)

**상황:** 아는 기술자 2명에게 내일 현장을 알리고 싶다.

1. **인원** 탭 → 그룹 선택 또는 새 그룹
2. **사람 추가** (이름·메모 수준으로)
3. 추가한 사람 카드 탭 → **명함 시트** 열림
4. **문자 초대** 또는 **카카오톡 초대** 시도
5. 명함의 **가능일정 캘린더**에서 이번 주 표시 확인

**성공 기준:** 초대 동작(문자 앱 열림/링크 복사) + 캘린더가 이해 가능

**기록할 것:**
- 초대 링크가 열리는지
- 캘린더 기호(● ○) 의미가 직관적인지

---

## 시나리오 C — "카톡 캡처로 일정 넣기" (선택, ~7분)

**상황:** 단톡방에 온 현장 안내 캡처가 있다.

1. **일정** 탭 → 일정 추가
2. **캡처 이미지 OCR** 또는 **텍스트 붙여넣기**
3. 자동 채워진 제목·날짜 확인 후 **수정**
4. 저장 후 캘린더에 표시 확인

**성공 기준:** OCR/붙여넣기 후 수동 수정만으로 일정 완성

**기록할 것:**
- OCR 정확도 (날짜·장소 틀림)
- 대기 시간이 길었는지

---

## 시나리오 D — "로그인·설정" (필수, ~5분)

1. **설정** 탭 → **카카오 로그인** (또는 테스트용 Mock 로그인)
2. 활동명(닉네임) 설정 화면이 나오면 1회 설정
3. 설정 상단에 **내 이름/프로필** 표시 확인
4. (가능하면) 앱 종료 후 다시 열어 로그인 유지 확인
5. **로그아웃** 시도 → *현재 버튼 없음: "로그아웃 버튼 없음"으로 피드백*
